Gene Symbol Matching

Wherever you write a gene name - a classification's gene symbol, a gene list, a filter box - it is matched to a gene by the same rule, so a name means the same gene everywhere. The rule follows HGNC, the committee that names human genes:

  1. A name that is a current HGNC symbol is taken as written, even if another gene lists it as an alias.
  2. A previous symbol - a gene HGNC has renamed - is matched to the gene's current symbol. A rename outranks an alias: SEPT2 is SEPTIN2's previous symbol and also one of SEPTIN6's aliases, so it is SEPTIN2.
  3. An alias - an informal name HGNC or NCBI records for a gene - is matched only when it names a single gene. An alias shared by several genes is ambiguous and is not matched; the message names the candidate genes so you can write the one you mean.

Names are matched regardless of case and surrounding whitespace. A symbol in this database with no HGNC record (an old Ensembl or RefSeq name) is kept as written, unless HGNC lists it as a previous symbol of a current gene, in which case the rename applies.

Where the rule is applied

  • A classification's gene symbol: the symbol of its matched c.HGVS, then the one the lab submitted, each taken to its current name. This is the symbol shown on the record and used for grouping, overlaps and exports.
    • {% if url_name_visible.classification_export %}
  • The classification export filter and the classification grid's gene symbol filter: an old name or alias finds the records under the current symbol; an ambiguous alias is reported.
    • {% endif %}
  • Condition matching and gene-disease relations, when a gene is named.
    • {% if url_name_visible.gene_lists %}
  • Gene lists, whether typed, pasted, uploaded or from PanelApp: the alias column shows the alias a name was matched through, and an ambiguous alias is left unmatched with its candidates in the error message.
    • {% endif %}
  • Gene level classifications: fusions (ROS1;GOPC) and whole-gene copy number calls name their genes the same way.

From symbol to gene ID

A gene list symbol then has to become Ensembl or RefSeq gene IDs for each gene annotation release, since a release's own symbols can lag HGNC. That step matches on the release's symbols and takes at most one alias hop in either direction, so two unrelated genes that happen to share an alias string (MT-TS2 and PDCD2 both have "RP8") are never linked. The gene list grid's match info shows which hop was taken.
