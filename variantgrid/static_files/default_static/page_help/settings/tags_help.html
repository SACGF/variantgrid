You can create as many tags as you like - but remember these are visible to everyone.

Allele origin says whether a tag belongs to germline work, somatic work, or both. It's used by the tag stats page, where a germline or somatic filter keeps the tags marked for that origin plus the ones marked "Both" - so a curator can drop the half of the vocabulary that isn't theirs.

Anyone creating a tag sets its allele origin. Changing it afterwards is an admin job. Allele origin doesn't affect which tags you can pick when tagging a variant, or what any analysis node returns.
