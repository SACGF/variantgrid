Drag and drop columns to add/remove and change ordering.

Mandatory columns

Every set of columns includes these - analyses do not work without them. They show a lock and can be reordered but not removed:

  • Tags - needed to add tags in an analysis
  • Tags in other analyses - all tags on the variant
  • Sample - where the per-sample genotype columns go

The variant column itself is always first and is not shown here.

Adding / Removing columns

  • My Columns - active columns. Top to bottom order is shown left to right in the grid.
  • Available columns - unused columns

Composite columns

Some columns draw several values in the one cell - the SpliceAI cell shows the maximum delta score and the individual predictions on hover, the gnomAD cell shows the overall and popmax frequencies with the rest of the population data on hover. A composite card lists what it shows, and its header offers the values it draws as alternative sort keys.

The columns drawn inside a composite are still exported and still available to filter nodes, so there is normally no need to add them separately. Tick Show columns already inside a composite to add one as a column of its own.
