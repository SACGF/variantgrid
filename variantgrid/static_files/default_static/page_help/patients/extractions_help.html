An extraction is the nucleic acid taken off a specimen. One tumour block gives both a DNA and an RNA extraction, and both belong to the same specimen.

A patient record import creates one extraction per specimen, from the nucleic acid source column - see import patient records details. The other arms are added from the specimen's own page, as is a re-extraction where the first did not yield enough material. The extraction date is what tells those apart.

One extraction may be sequenced more than once (repeats, top-ups), so it can have several samples. A sample naming an extraction that has not been accessioned yet is parked rather than rejected, and re-resolved as extractions arrive - the ones still waiting are listed on Unmatched extractions.
