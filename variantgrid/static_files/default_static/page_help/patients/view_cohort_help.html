• Add samples by name in the Add sample box, or bring in a whole file with add every sample from.
  • Remove drops a sample you have just added. A sample the saved cohort already has stays struck through until you save, so you can undo it.
  • Drag rows by the handle to set the order samples appear in.
  • Adds, removals and re-ordering are all applied together when you press Save cohort.
  • Tick saved samples to make a Duo, Trio or Quad analysis from them, or a new cohort of just those samples.
  • Samples all from one VCF save as a sub cohort, instantly. Samples from several VCFs are merged by a background job, and a sample is recorded as no call (not REF) at any site its own VCF didn't call - prefer a joint called VCF for a family: de novo and recessive filters treat a parent's no call as "no variant", so in a merged cohort a parent with no coverage at a site looks the same as a parent who is REF.
  • You can only add samples from the build you created the cohort with. See Cohorts page in help
