An extraction is the nucleic acid taken off a specimen. One tumour block gives both a DNA and an RNA extraction, and both belong to the same specimen.

Add the specimen on the Specimens tab first, then pick it here.

The extraction date is what tells apart two extractions of the same nucleic acid from one specimen, eg where the first did not yield enough material.

One extraction may be sequenced more than once (repeats, top-ups), so it can have several samples.
