An AnnotationVersion is composed of sub types: Variant Level, Gene level, ClinVar, Ontology and Human Protein Atlas.

They are updated by someone manually changing pipelines or updating annotation files on the server.

Each of these tools can be upgraded separately, changing one will create a new master AnnotationVersion which is used to version analyses and diagnoses.

This allows you to keep track of past annotations, as well as compare results from new annotations vs old.

VariantAnnotationVersion may be present but not active. This is so you can install a new version and run the annotation (which may take a few days for very large servers) while still using existing annotation as the default.

AnnotSV is versioned separately from VEP: each build lists the AnnotSV versions registered (its -version and annotation bundle) and the command line it runs with. A new version is promoted on the annotation runs page.
