Composite cells draw several columns at once: the first member is the headline the cell reads as and sorts by, the rest are on hover, and the ▾ in the column header sorts the grid by any of them. A member riding along inside a cell is still written to the CSV and still offered in the filter builder, and you can show any of them standalone from VariantGrid Columns. The example cells here are drawn by the grid's own renderers from made up data - no real variant, sample or lab appears on this page. Variant and transcript level annotations come from an annotation run. Each run writes a numbered columns version - a newer version adds columns and can read a column from a different source (eg gnomAD v3 to v4). The toggle at the top shows the columns as one version writes them, or every version at once with each row noting the versions it applies to. Each column lists the tool it came from:
  • Variant - the variant's own coordinates, and what follows straight from them (g.HGVS)
  • VEP - Ensembl Variant Effect Predictor, including its plugins and custom data files, eg dbNSFP - a collection of many different resources
  • AnnotSV - AnnotSV annotates structural variants (so these columns are populated for SVs only)
  • ClinVar - the ClinVar record for the variant, loaded separately from VEP
  • VariantGrid - calculated by VariantGrid while importing annotation, or from its own records (classifications, tags)
  • VCF - a FORMAT field read straight off the imported VCF
