Composite cells draw several columns at once: the first member is the headline the cell reads as and sorts by, the rest are on hover, and the ▾ in the column header sorts the grid by any of them. A member riding along inside a cell is still written to the CSV and still offered in the filter builder, and you can show any of them standalone from VariantGrid Columns. The example cells here are drawn by the grid's own renderers from made up data - no real variant, sample or lab appears on this page. Variant and transcript level annotations come from an annotation run. Each column lists the tool it came from:
  • VEP - Ensembl Variant Effect Predictor, including its plugins and custom data files, eg dbNSFP - a collection of many different resources
  • AnnotSV - AnnotSV annotates structural variants (so these columns are populated for SVs only)
  • VariantGrid - calculated by VariantGrid while importing annotation
  • VCF - a FORMAT field read straight off the imported VCF
