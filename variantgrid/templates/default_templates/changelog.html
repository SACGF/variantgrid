VariantGrid 4.0

Analysis

  • Performance improvements: node counts, node loading, adding tags
  • Performance improvement creating analysis from template
  • Prevent users from loading nodes multiple times by repeated clicking (this was causing performance issues)
  • #139 - Analysis grid tags / classifications take into account sharing / withdrawn
  • #137 - Tags in analysis shown on analysis listing page
  • New Node - MOI (Mode of Inheritance) - uses zygosity and gene/disease associations (GenCC)
  • EffectNode - has been changed to use the new pathogenicity columns, it automatically switches based on the annotation version used.
  • Tissue Node works again (new Human Protein Atlas annotation)
  • Trio Node Proband HET option removed + replaced with SampleNode (which is faster)
  • Population node, can exclude filtered by gnomAD
  • PhenotypeNode - support MONDO, shows a warning if ontology term doesn't map to genes
  • New Node - Conservation
  • New analysis type - Quad (a trio plus an affected sibling). Has its own creation wizard and page, and the Trio/Quad nodes show a table of zygosities, with options for combined recessive filtering, "any affected", and requiring the affected sibling's zygosity
  • Analysis templates can be configured to auto-launch when a sample is imported
  • Audit log - records which nodes were added/configured, by who and when
  • All Variants node - filter by variant type (eg symbolic) and by chromosome/contig
  • Analysis grid - sample column labels can show patient name. Much faster CSV export when using canonical transcripts
  • More performance work - the node editor no longer waits for the grid, large nodes (over 50k variants by default) don't auto-load their grid, and large grids no longer auto-sort
  • Node CSV/VCF exports are generated in the background, with progress shown on the analysis toolbar so they survive clicking through to other nodes
  • Nodes redesigned - cards with icons and info chips, clearer source/filter colours
  • Horizontal mode - nodes flow left to right, with the variant grid docked full width along the bottom and variant details shown as tabs
  • Somatic classifications - node germline/somatic toggle and tier pills, grid germline/somatic boxes, Tier I/II node count
  • Node counts record their data sources - exact vs advisory when the data may have changed

Annotation

  • New dbNSFP gene columns (see annotation descriptions) GDI, GDI-Phred, P(HI), GHIS, P(rec), HIPred_score, Gene_indispensability_score, Expression(egenetics), Expression(GNF/Atlas), BioCarta Pathway, ConsensusPathDB Pathway, KEGG IDs, KEGG Pathway, GWAS traits, GO process, GO cellular, GO mol function, BioGRID interactions, ConsensusPathDB interactions, gnomAD prob LOF intolerant, gnomAD prob LOF HOM, gnomAD prob LOF tolerant, Essential Gene (CRISPR), Essential Gene (CRISPR2), Essential Gene (Gene Trap)
  • New columns - ALoFT, NMD Escaping Variant
  • Gene annotation column changes:
    • omim/hpo terms now only use direct links (was too broad due to indirect links)
    • New column "MONDO terms"
    • New MOI columns: eg for GATA2 they would be:
      Gene/Disease Supportive or below: monocytopenia with susceptibility to infections=Autosomal dominant (Supportive: Orphanet)
      Gene/Disease Moderate or above: deafness-lymphedema-leukemia syndrome=Autosomal dominant (Definitive: TGMI|G2P Strong: Genomics England PanelApp)|acute myeloid leukemia=Autosomal dominant (Strong: Genomics England PanelApp)|myelodysplastic syndrome=Autosomal dominant (Strong: Genomics England PanelApp)|GATA2 deficiency with susceptibility to MDS/AML=Autosomal dominant (Definitive: ClinGen)
  • Update VEP (v116), updated Mastermind, COSMIC
  • Pathogenicity Predictions have changed:
    • New columns added: Alphamissense, BayesDel (NoAF), CADD (raw), ClinPred, REVEL, MetaLR, VEST4.

      These are "rankscores" ie scores scaled 0->1 based on all of the scores in non-synonymous SNVs. There is 1 score per variant (not per transcript)

      Previously, we used levels (eg DAMAGING, BENIGN etc), but these were made by taking genome-wide thresholds, and it has been shown that this varies considerably per-gene. We plan on developing further refinements here, eg being able to automatically use this tool/cutoff for these genes, a different tool/cutoff for other genes etc.

    • Old columns removed: FATHMM, Mutation Assessor, Mutation Taster, Polyphen2, CADD Phred, REVEL Score
  • gnomAD v4.1, added some extra fields for GRCh37 gnomAD (v2)
  • Added MAVEdb info/links
  • New columns - hgvs_g, svlen (Structural Variant length), total_db_ref (global variant zygosity count), total_db_unk, predictions_num_benign, predictions_num_pathogenic
  • dbNSFP 5.3.1 - new columns, and VEP 116 plugin columns (eg Promoter AI) shown on variant details
  • denovoDB, and AnnotSV for structural variants (own pipeline - upgrade without re-running VEP)
  • SpliceAI is now run as a command so indels are scored. Raw (rather than masked) scores are flagged with a warning
  • AnnotSV annotations shown on the variant details page and grids
  • Annotation descriptions page covers AnnotSV and calculated columns, not just VEP
  • Annotation pipeline - runs are merged into larger batches, new runs pause when the annotation disk is low, and temporary files are cleaned up once a run has imported. The VCF/Sample page shows any variants that couldn't be annotated

Classification

  • Somatic classifications, including new somatic evidence keys
  • New pathogenicity prediction tool scores now autopopulate classifications
  • Candidate search - re-runs analyses against existing classifications, to find variants that were missed or whose classification has since changed
  • Setting to highlight research classifications
  • Reclassification analytics - reclassification rates, VUS rate over time, gene burden

Data

  • Download annotated CSV/VCF from VCF/sample page. These are generated offline, so the download itself is fast
  • Samples page (data) - filter for variant type. Fix autocompletes sometimes not searching all builds
  • Cohorts / Pedigree - added user to to make it easier to find
  • Data archive - VCF data can be dumped without losing the metadata, so previous analyses still make sense
  • Upload / Download API
  • File upload widget replaced with Filepond (the old jQuery File Upload had been abandoned upstream)

Data Sharing

  • GA4GH Beacon v2 - variants can be exposed to other beacons, and an analysis can query external beacons (switched on per node), with CNV and somatic support
  • Support for MatchMaker Exchange (MME) - rare disease patient matching against other MME nodes. A classification is shared once it's set to the 'public' share level - the classification page shows a card telling you whether that record is eligible. Genes are published as HGNC symbol, Entrez and Ensembl gene IDs, and inbound queries match on any of those (including aliases and superseded symbols). There are public metrics and disclaimers pages, bearer token authentication, and notifications when a match comes in

Genes

  • Switch to BioCommons HGVS library (includes adding support for 'inv')
  • Gene Symbol page has been rearranged/updated with new annotation fields
  • Gene/Disease - use GenCC (includes ClinGen) instead of just ClinGen on Gene page, Gene Grid column
  • PanelApp panels are matched on HGNC ID rather than the gene symbol from a dated snapshot, and deleted panels are handled
  • Gene Lists - faster grid, copy/paste genes in, and a graphs tab showing gene locations
  • A mitochondrial 'm.' HGVS on a non-MT reference now warns rather than silently resolving as 'g.'

Genome Builds

  • Telomere to telomere build - T2T-CHM13v2 (experimental - not all functionality and annotation available)
  • GenomeBuild / Contig pages (eg search for "chrX")

Liftover

  • bcftools +liftover handles anything the ClinGen Allele Registry can't lift over, and an event is raised when the registry is unavailable
  • Liftover runs in parallel batches - faster, a failure only loses its batch

Ontology

  • Ontology can have multiple versions (allowing upgrades over time)
  • Patients - phenotype text also matched for MONDO terms
  • Update ontologies to latest versions (and will be able to do this going forward)
  • Ontology term page shows classifications and patients linked to term

Patients / Phenotypes

  • Phenotype matching - an alias can now match multiple terms (and warns when it does), ambiguous matches are shown, auto-matched terms can be skipped or disabled, and bulk matching is much faster
  • Patient imports - improved grids showing more info, and the original CSV can be downloaded
  • Patient graphs only count patients you have permission to see
  • New Specimen and Extraction records - pages, grids and an API

Search

  • Search rewritten - gives clearer results, and indication of what was searched in green
  • Can now search for cohort/pedigree, ontology terms
  • dbSNP lookup is faster
  • Improved HGVS resolution (support for gaps, LRG, non-coding transcripts)
  • Manual variant entry - improved user experience creating novel variants via search
  • Search for EnrichmentKit, Trios and Quads, and versioned Ensembl genes (eg "ENSG00000243646.11")
  • COSMIC variants we don't already have can be created from search (uses the COSMIC API)
  • The analysis shortcut prefix is now "an" (eg "an42") as it conflicted with allele

Structural Variants

  • BCFtools is used for normalisation (the old program VT does not support symbolic alts), adding support for symbolic INV, and VCF export includes SVLEN
  • Gene overlaps calculated for structural variants
  • Variant page works correctly for very long variants
  • Gene fusions imported as variants (VICC nomenclature)

Tagging

  • VGP#2439 - Tag Colors used to be 1 per user, can now have multiple which can be shared/set globally (so all lab members can share colors)
  • Tags for Variants grid - grid showing all tags per variant has been put back (was disabled for performance reasons)
  • Tag stats page - counts, over time, by user / lab / gene, co-occurrence
  • Merge duplicate tags, tag operations logged
  • Tag sort order set on tag colors page, old tags marked stale

User Interface

  • Every grid on the site has been converted from jqGrid to DataTables - sorting, filtering and downloads throughout
  • Grid download filenames include a date suffix, and analysis exports record the node version
  • Lab heads can add and remove members on their lab page
  • Faster page loads - related data, ontology versions and contigs no longer run a query per row
  • Page titles prefixed with the site name, variant / allele pages named by short label

Variant Details

  • Show other variants on locus regardless of genotype calls, also link to alleles that were once on the same row in VCF files
  • Samples with variant - shows samples from every genome build, with zygosity, classifications, VCF filters, and can be shown/hidden by zygosity
  • Quick links to AlphaFold predictions
  • Less scrolling - initially shows 8 transcripts, annotation version is collapsed by default, and RepeatMasker is collapsed down into classes
  • Genome build switcher buttons only appear for builds the variant actually exists in
  • #215 - show a quick summary of gene info (gene/disease links - click to expand)
  • #788 - show tag counts in grid (showing all tags could get extremely long)
  • #13 - MANE transcripts indicated and chosen as default transcript on variant details page/classification
  • #109 - Allow users to see (limited) annotation on intergenic variants
  • #668 - add tooltips to show help about columns on gene / variant pages
  • Nearby variants shows tags and classification summary counts, works across builds
  • Page appears differently for Structural Variants (hiding unavailable annotations, add notes)

Variant Grids

  • #743 - variant grids - fix up column labels. Make some new links (ontology terms,pubmed, dbsnp) -
  • #733 - Variant pages (gene symbol, all variants, tags etc) now styled/links the same as on Anaylsis grid

VCF upload

  • #660 - Give warning if VCF filters are not defined in header (rather than fail to import VCF)
  • chrM variants are no longer skipped during import
  • g.VCF files are handled properly, and "ref=N" is converted to the real reference sequence
  • Progress is shown while an uploaded VCF is being annotated
  • Manual variant entry import handles partial failures gracefully
  • Unsorted VCFs are sorted during import (with a warning) rather than failing
