Data & privacy

What happens to the data you upload to {{ site_name }}.

Who can see your data

    {% if private_user_labs %}
  • New users who register themselves get their own private lab, so nothing they upload is shared with anyone else by default.
    • {% endif %}
  • An upload can be read by the uploader's lab and organisation, and by anyone it is explicitly shared with. Which groups get access to new uploads can be changed in your user settings.
  • Some data is deliberately shared with all users. {% if data_privacy.shared_data %}{{ data_privacy.shared_data }}{% endif %}
  • System administrators can see everything. They look at user data only to diagnose a problem (eg a failed import); otherwise it appears only in aggregate statistics (eg import times).

Getting a lab for your institution

  1. Request a lab using an email address on your institution's website domain.
  2. Confirm the request with the link emailed to that address.
  3. An administrator checks and approves the request.
  4. You become the lab head, and can add colleagues to the lab.

Deleting data

  • Deleting an upload removes the uploaded file and its genotypes. Deleting only the VCF removes its samples and genotypes, but keeps the uploaded file until the upload is deleted too.
  • Variants are stored once and shared by every sample that has them. A variant left behind carries nothing about who uploaded it or which samples had it.
