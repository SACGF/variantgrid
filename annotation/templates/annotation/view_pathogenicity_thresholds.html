Pathogenicity Thresholds

VariantGrid filters and colours missense pathogenicity prediction scores using the ClinGen-calibrated PP3 (pathogenic supporting) and BP4 (benign supporting) raw-score cutoffs below. A score ≥ the PP3 threshold supports pathogenic; a score ≤ the BP4 threshold supports benign; values in between are indeterminate. Tools without a published ClinGen calibration use the author-recommended cutoff (single threshold) or, where noted, have no calibrated threshold. The last rows are not missense pathogenicity predictors at all - they are offered as Effect node filters only, and take no part in the colour bands or the damage count.

These thresholds drive the colour bands on the analysis Effect (Damage) node sliders and the Pathogenicity card on the variant details page. Every coloured number on the variant details page comes from this page - a field that isn't listed here is shown plain.

Rankscores

Rankscores are each tool's raw score expressed as its rank among all dbNSFP variants, so one pair of cutoffs bands them all: benign supporting ≤ {{ max_benign_rankscore }} and pathogenic supporting ≥ {{ min_pathogenic_rankscore }} (settings ANNOTATION_MAX_BENIGN_RANKSCORE / ANNOTATION_MIN_PATHOGENIC_RANKSCORE).
