# commands map

Generated by `vg map commands` (do not edit; run `scripts/vg map commands` after adding a command). One table per category, from `Command.category`: **ops** (run on a deployment as part of operating it), **import** (load reference or user data), **maintenance** (recompute or repair on demand), **one-off** (a data migration kept until every deployment has run it), **dev** (development and introspection). A command without a declared category is marked `(guessed)`. Models touched lists the apps whose models the command module imports.
