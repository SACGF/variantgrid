private#223 — SampleNode on the canvas

Cards are drawn with the real analysis_nodes.css rules (64px wide, 10px base font). The first strip is actual size; the second is the same DOM at 2.2× so the chips are readable. Two new CSS rules are proposed: .node-chip-warning and (option C only) .node-badge-sub.

1. The four levels recommended

Same pedigree badge at every level — it has always drawn the patient, and every level resolves to one. The class strip says what the node actually is. Chips are the hierarchy from the picked object down, nested the way the relations are: specimen ⊃ extraction ⊃ one VCF ×N leaf. The picked object is the outermost chip, so an extraction node carries the flask and a sample node the VCF icon. An amber ⚠ ×N counts anything left out.

Chip icons follow each model's own preview_icon(): specimen droplet, extraction flask, VCF . Group labels are the tissue (else status, else reference id) for a specimen and the nucleic acid for an extraction; hover is the full str(). VCFs are always one VCF ×N chip whose hover lists the names; the ⚠ chip's hover lists the reasons. Above 3 extractions or specimens in one group they collapse to a ×N label, the existing MAX_VCF_CHIPS rule applied per group.

Icon pairs — specimen vs extraction

Vial and flask are both glassware. Candidates below, drawn on the specimen card where the two sit together. At chip size what separates icons is silhouette — a blob for the specimen, a stick for the extraction. Already taken elsewhere in the app: fa-flask = Lab, fa-dna = Gene, fa-microscope = Sample, fa-lungs = Tissue node, fa-flask-vial = seqauto.

Extraction strip label — the 45px problem

The strip has ~45px for text at 7px bold, and EXTRACTION doesn't fit. With the flask chip already saying DNA, the 6px strip is the main row's pick.

3. Add-node menu

Four entries under Source, each creating a SampleNode with source_level stamped. Icons in the menu are the models' own so they match the chips. On the canvas the badge is still the pedigree.
