Analysis node icons v2 — Design A locked in

Round 2, incorporating feedback on analysis_node_icons.html: Design A (corner type-badge + class strip + text body + count strip) is the layout. This file reworks the icons that missed — Pedigree, Gene List, Allele Frequency, Population, MOI, Intervals, Merge — shows the richer Sample node (patient shape / extraction / VCFs), and finishes with the whole node palette rendered in Design A. Recommended picks have the amber outline; hover anything for its name.

Sample node — patient / extraction / VCF layers

The canvas keeps the pedigree shape (□ male / ○ female / diagonal = deceased) — it carries real information. The dropdown/menu mini-icon becomes a plain square SVG. On the node itself we can then layer what the sample actually is: shape = patient, test tube = extraction (when applicable), file chip(s) = the VCF(s) — with multiples shown when a patient/extraction has several VCFs.

Reworked icons

Pedigree — needs to not look like a Quad

v1 attempt — yes, it's just the Quad
3 generations, 8 people — unmistakably a pedigree
wide sibship variant (2 gens, 4 sibs)
The 3-generation glyph wins: depth is what distinguishes a pedigree from Trio/Quad. At badge size (16px) it simplifies to the same shape with dots for the bottom row.

Gene List — "a list of gene names"

your "G--" idea: G + name bars
real gene names (blurs below ~28px)
plain bullet list (generic)
helix + list rows
The G-column version reads as "list of things that all start like gene symbols" and survives small sizes because the G is the only letterform. At 16px badge size the G stays legible where full gene names don't.

Allele Frequency

fa-chart-simple — minimalist, no axis
text badge "AF%"
Decided: both, in different slots — fa-chart-simple as the badge icon, and "AF%" as the class-strip label (instead of spelling out "Allele Freq"). See it in the palette below.

Population — globe it is

fa-earth-oceania — decided
the 3×3 crowd — considered, not taken
Decided: globe. Works at every size including the 26px badge, and cleanly separates "world populations / gnomAD" from Cohort's people. (Randomised crowd kept above for posterity — still works.)

Mode of Inheritance — needs to not look like a Trio

allele transmission: Aa ↓ aa
the modes themselves: AD/AR/XL
generations cascading down
chromosome pair, one passed down
No people-shapes at all, so no Trio confusion. Aa ↓ aa is the pick — it's the textbook notation for transmission and pairs beautifully with the Punnett-square Zygosity icon (same monospace letterform family). AD/AR/XL is the runner-up if you'd rather name the modes.

Intervals Intersection — a BED file on a chromosome

bands + arrows pointing at them
arrows only (plain chromosome)
bands only
Bands + arrows (left): each arrow lands on a filled band, so arrows say "look here" and bands say "these regions" — the fullest picture of a BED file and still clean, because arrows and bands share the same three x-positions. Badge-size (16px) drops the arrows and keeps chromosome + one band.

Merge — three lanes into one

Icon only — the node's top surface / drop-target mechanics stay as they are. A downward merge-road-sign with three lanes:

3 lanes merging into one arrow
3 separate arrows converging on a point
fa-code-merge (v1 pick, for comparison)
Three-lanes-into-one (left) — the road-sign metaphor everyone knows, turned downward to match the DAG's flow, and the three lanes hint at "many parents" better than git's two-branch glyph. Reads at badge size because it's just four strokes.

Selected In Parent

fa-square-check
Created from the grid's tick-box rather than the dropdown, so it only needs a canvas badge — the tick-box glyph is self-describing. Settled.
