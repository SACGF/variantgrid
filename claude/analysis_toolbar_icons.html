Analysis toolbar — icon options

The node cards are now FontAwesome + inline SVG in currentColor, but the top bar is still eight unrelated 16×16 PNGs (add-icon.png, copy.png, delete-icon.png, settings-icon.png, tags_colored.png, samples_icon_small.png, multiple_monitors.png) at three different sizes. Below: the baseline, five whole-bar treatments, then per-button glyph candidates. Recommended picks carry the amber outline; hover anything for its tooltip.

Baseline — what's there now

Sample GRCh38

Mixed metaphors (glossy 3D tags vs flat blue plus), mixed sizes (16/19/22px), no hover state, and no visual grouping between "edit the graph" and "open a panel" actions.

Whole-bar options

Option A — flat mono

One weight, one colour (#3d4550), 15px FA solid, square hover chip. Thin separators split graph-editing from panel-opening. Same footprint as today.

Sample GRCh38
Recommended. Cheapest change, reads as one family with the node cards, keeps the bar quiet so the canvas stays the focus.

Option B — segmented groups

Same glyphs, but the two groups become bordered button groups, Bootstrap btn-group style. Makes the grouping explicit rather than implied.

Sample GRCh38
More structured, but the boxes add chrome to a bar that sits directly above a busy canvas.

Option C — semantic colour

Mono base, but the three destructive/creative actions borrow the node palette: add = source green #0e7a4a, copy = filter blue #3455a4, delete = red, tags = amber. Round hover chip.

Sample GRCh38
Fast to scan and delete is unmistakable; the green/blue pair does pull double duty with the source/filter meaning on the cards.

Option D — icon + label

Labels instead of tooltips. Bigger targets, self-documenting for new users, and it fills the bar the analysis header already had spare.

Sample GRCh38
Clearest, widest. On a narrow window the labels will crowd #analysis-info (genome build / jobs / downloads), so it'd want the labels dropping under a media query.

Option E — filled primary action

"Add node" is the one thing you do constantly, so it becomes a filled button next to the type selector; everything else stays a quiet ghost icon.

Sample GRCh38
Ties the selector and the add action together visually, which matches how they're actually used. Green here is the source colour again — it could be neutral grey instead.
